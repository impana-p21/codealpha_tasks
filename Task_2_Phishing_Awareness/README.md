# Task 2 - Phishing Awareness Training

## Objective

To create a phishing awareness training module that explains common phishing attacks, social engineering techniques, warning signs, prevention methods, and safe cybersecurity practices.

## Contents

- `phishing_awareness.py` - Interactive Python-based awareness and quiz program.
- `phishing_awareness_report.md` - Detailed documentation of phishing concepts and prevention techniques.

## Topics Covered

- Email Phishing
- Spear Phishing
- Smishing
- Vishing
- Fake Websites
- Social Engineering
- Phishing Warning Signs
- Prevention Best Practices
- Interactive Quiz

## Technologies Used

- Python
- Markdown
